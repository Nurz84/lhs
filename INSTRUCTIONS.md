# 🎮 Loot Hunter Stories — Инструкция по запуску

## 🚀 Быстрый старт

### 1. Установка зависимостей
```bash
npm install
```

### 2. Запуск для разработки
```bash
npm run dev
```
Откройте http://localhost:5173 в браузере

### 3. Сборка для продакшена
```bash
npm run build
```
Готовые файлы будут в папке `dist/`

### 4. Создание ZIP для Яндекс Игр
```bash
# Linux/Mac
cd dist && zip -r ../loot-hunter-stories.zip . && cd ..

# Windows (PowerShell)
Compress-Archive -Path dist\* -DestinationPath loot-hunter-stories.zip
```

## 📋 Что реализовано

### ✅ Интеграция с Яндекс Играми
- **Yandex Games SDK** — полная интеграция (`src/yandexSdk.ts`)
- **Облачные сохранения** — автосохранение каждые 30 секунд
- **Rewarded Video** — реклама за вознаграждение (готово к использованию)
- **Interstitial** — межстраничная реклама при смене зоны
- **Лидерборды** — отправка рекордов (уровень и зона)
- **Аналитика** — отслеживание событий
- **Пауза игры** — во время показа рекламы

### ✅ Игровые механики
- 10 типов монстров + 10 боссов
- 10 уровней редкости предметов
- 8 слотов экипировки
- Сетовые предметы (5 сетов)
- Уникальные именные артефакты
- 10 активных навыков
- 12 пассивных улучшений
- 6 NPC-торговцев
- 6 сезонных лиг с модификаторами
- Система зон с масштабированием

## 🎯 Перед публикацией на Яндекс Играх

### 1. Настройте лидерборды в консоли Яндекс
Перейдите в консоль разработчика → Ваша игра → Лидерборды:
- Создайте `main` (числовой, по убыванию)
- Создайте `zone` (числовой, по убыванию)

### 2. Добавьте rewarded-награды в UI
Примеры в `README.md` в разделе "Что нужно сделать перед публикацией"

### 3. Протестируйте локально
```bash
npm run dev
```
- SDK работает в fallback-режиме
- Реклама пропускается, награды выдаются
- Сохранения работают через localStorage

### 4. Загрузите на Яндекс Игры
1. games.yandex.ru → Консоль разработчика
2. Загрузите `loot-hunter-stories.zip`
3. Заполните описание, добавьте скриншоты
4. Отправьте на модерацию

## 💡 Советы по монетизации

### Rewarded Video (основной доход):
- Удвоение золота за босса
- Бесплатная трансмутация у Мистика
- Бонус удачи +50% на 30 минут
- Бесплатное улучшение предмета

### Interstitial (дополнительный доход):
- Показывается при смене зоны (каждые 10 убийств)
- Кулдаун 2 минуты между показами
- Игра ставится на паузу

### Ожидаемый доход (при 1000 DAU):
- Rewarded: ~500-1000₽/день
- Interstitial: ~200-400₽/день
- **Итого**: ~21-42K₽/месяц

## 🐛 Локальная разработка

SDK автоматически работает в fallback-режиме при локальном запуске:
- Реклама пропускается, но награды выдаются
- Сохранения работают через localStorage
- Лидерборды не отправляются
- Аналитика не отправляется

Это позволяет тестировать игру без доступа к платформе Яндекс.

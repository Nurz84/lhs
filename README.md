### 4. Добавить ежедневные награды

```typescript
const [lastDailyReward, setLastDailyReward] = useState(0);

const claimDailyReward = () => {
  const now = Date.now();
  const lastReward = lastDailyReward;
  const hoursSinceLastReward = (now - lastReward) / (1000 * 60 * 60);
  
  if (hoursSinceLastReward >= 24) {
    const goldReward = 100 * character.level;
    const xpReward = 50 * character.level;
    
    setCharacter(prev => ({
      ...prev,
      gold: prev.gold + goldReward,
      xp: prev.xp + xpReward
    }));
    
    setLastDailyReward(now);
    YandexSDK.trackEvent('daily_reward_claimed', { gold: goldReward, xp: xpReward });
    
    // Показать rewarded ad для удвоения
    requestRewardedAd('double_daily', () => {
      setCharacter(prev => ({
        ...prev,
        gold: prev.gold + goldReward,
        xp: prev.xp + xpReward
      }));
    });
  }
};
```

## 📊 Аналитика и метрики

### Ключевые метрики для отслеживания:
- **DAU/MAU** — активные игроки
- **Session length** — средняя длительность сессии
- **Retention D1/D7/D30** — удержание
- **ARPDAU** — доход на пользователя в день
- **Ad conversion** — конверсия в просмотр рекламы

### Целевые показатели:
- Retention D1: > 40%
- Retention D7: > 20%
- Session length: > 10 минут
- Ad views per session: 2-4
